Architecture

Public map only. No secrets. No processor keys. No runnable payout logic.

Purpose

AlwaysConnected keeps three jobs in one stack: reachability, visible automation, and a cheap public front door.

Layers

  1. Public surface. This site, README, and docs on GitHub Pages.
  2. Control plane. Private agent board, job ledger, human gates.
  3. Execution. Local / Termux / hosted runners with allow-lists.
  4. Money movement. Official processors only. Keys never enter git.

Never commit

Passwords, tokens, Stripe/Plaid secrets, customer PII, or anything that stays dangerous because this repository is public.
